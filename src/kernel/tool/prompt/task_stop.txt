Stops an owned background task by task_id.

Use this when a task is no longer needed — the plan changed, the answer arrived another
way, or it is clearly stuck. Leaving work running costs tokens and can produce writes you
no longer want.

Parameters:
- task_id (required): from the launch call or `task_list`.
- force (optional, default false): force cancellation. Managed services normally
  receive a cooperative stop request; ordinary jobs retain cancellation behavior.

Stopping is asynchronous. Check task_output for the actual process exit and
cleanup outcome. Uncooperative services may require forced termination and
effect inspection. Neither stopping nor cancellation rolls back completed work
or proves that project checks passed.
