# 1.0.6-preview.1：完成验证反馈修复

状态：准备中，尚未发布。公开稳定版为1.0.5，公开Preview仍为1.0.6-preview.0。本页不表示新发行已可下载。

本轮由发布后真实Qwen/YOLO冒烟触发：模型正确写出目标文件，并自行修正第一次shell算术错误，但两个成功自定义检查未被完成验证器识别。验证反馈只返回`checks_required`，没有给出可操作的检查路径，最终耗尽8次冒烟请求。

修复把同一验证说明接入系统提示词、bash详细说明与阻断反馈。自定义文件、文档、接口检查可用真实断言测试，例如编写`verify.test.mjs`后请求执行`node --test verify.test.mjs`；断言失败必须让进程失败。已有项目优先使用真实的测试/构建命令。中文会话获得中文修复提示。

同时修复失败原因标签被对象合并覆盖的问题：失败检查保持`failed_check`，而不是误显示`project`。不同测试成功不能清除原失败检查，修改之前的测试不能证明之后的修改，未知效果和未收尾子任务仍不能标为成功。模型仅声明完成、打印PASS或执行任意返回0的shell不会通过验收。

验证器记录的是实际检查进程，而非完整语义验收。`node --check`只检查语法，`git diff --check`只检查文档差异空白格式；应按真实用户需求补充内容/功能断言。只读和Plan任务不得为了获取验证回执创建或修改文件。

本次源版本统一为1.0.6-preview.1，Android版本码预留10012。Web/Android布局和交互按键不变；同一个设备运行时修复后，各端获得一致的完成状态与反馈。原Preview公开包的失败、日志和额度记录保持原样。

五场景模型评测（全栈、文档、检索、艺术网页、算法，各两轮）尚未执行。下一公开包仍须通过自身CI、打包、签名与匿名下载验证后，注册有界新评测；不得将受控提供者测试说成Qwen实测，也不得自动扩展旧额度。
