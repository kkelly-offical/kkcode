# 1.0.6-preview.1：完成验证反馈修复

状态：准备中，尚未发布。公开稳定版为1.0.5，公开Preview仍为1.0.6-preview.0。本页不表示新发行已可下载。

本轮由发布后真实Qwen/YOLO冒烟触发：模型正确写出目标文件，并自行修正第一次shell算术错误，但两个成功自定义检查未被完成验证器识别。验证反馈只返回`checks_required`，没有给出可操作的检查路径，最终耗尽8次冒烟请求。

修复把同一验证说明接入系统提示词、bash详细说明与阻断反馈。自定义文件、文档、接口检查可用真实断言测试，例如编写`verify.test.mjs`后请求执行`node --test verify.test.mjs`；断言失败必须让进程失败。已有项目优先使用真实的测试/构建命令。中文会话获得中文修复提示。

同时修复失败原因标签被对象合并覆盖的问题：失败检查保持`failed_check`，而不是误显示`project`。不同测试成功不能清除原失败检查，修改之前的测试不能证明之后的修改，未知效果和未收尾子任务仍不能标为成功。模型仅声明完成、打印PASS或执行任意返回0的shell不会通过验收。

进一步的候选全栈测试发现目录绑定、编辑修复路径重复、执行前拒绝和后台核查链的问题。本轮已补齐：确定的`cd … &&`检查身份、逐文件修复、宿主未执行回执、后台进程独立操作账本，以及明确的`inspection-required`停止状态。提供者出错时保留此前验证失败，避免失去恢复依据。需要核查的状态不再让模型继续盲目重试。

后续修复把OpenAI、Responses、Anthropic、Ollama和模型目录请求接入专用传输层，避免用户配置较长等待期限时仍被底层300秒默认限制提前中断；显式取消、流式无数据期限、响应容量和重定向防护保持有效。已核查、后置检查通过并被接受的后台任务，不再要求之后每个普通问题重复测试。私密操作日志的原子替换竞态通过有界重新打开处理，权限/所有者/硬链接校验不放宽。

运行错误、取消、步骤耗尽和无进展停止，也会刷新最后的实际验证证据，避免继续显示修复前的失败或漏掉后来未验证的修改。错误依旧是错误，检查通过不自动补造最终回答或任务完成；后台/子任务/未知效果仍须核查。可复跑测试应保留，清理后再修改的状态必须重新验证。

编辑保存改用随机私有暂存，避免固定备份名的软链接干扰；保留已有普通文件的执行位、普通POSIX权限和所有者，失败不把旧备份盖回目标。准备期间检测到文件变化会要求重新读取，软链接/硬链接目标须选择真实普通文件。修改后的代码不保留setuid/setgid，扩展ACL/xattr不在这次保证范围。该修复还在候选验收中，不表示已公开发布。

模型的私有验收修复提示会定位精确检查参数和目录，帮助单独补跑旧的未核实检查，不重放准备/清理；凭据和环境值不写入公共回执。`bash`说明与实际Unix `/bin/sh`/Windows cmd一致，后台回执明确显示有限命令期限，不能当作持久服务。旧的全局调用计数压缩建议不再污染工具结果，各端继续使用真实的会话上下文计量和自动压缩。

原生编辑会在操作前检查全部目标；别名的早期拒绝不会伪装成已执行修改。批量编辑先合并最终内容，并发改变的文件不会被旧备份盖回；恢复失败明确保留部分结果，取消不是回滚。新文件恢复路径在回执中给出。默认回收站拒绝工作区可控目录软链接，每次移除使用私有独立目录，旧回收站保留不动；跨卷使用源所在卷的可恢复路径。

验证器记录的是实际检查进程，而非完整语义验收。`node --check`只检查语法，`git diff --check`只检查文档差异空白格式；应按真实用户需求补充内容/功能断言。只读和Plan任务不得为了获取验证回执创建或修改文件。

本次源版本统一为1.0.6-preview.1，Android版本码预留10012。Web/Android布局和交互按键不变；同一个设备运行时修复后，各端获得一致的完成状态与反馈。原Preview公开包的失败、日志和额度记录保持原样。

五场景模型评测（全栈、文档、检索、艺术网页、算法，各两轮）尚未完成。第一项冻结候选全栈试跑失败，后续修复与重新验收分开记录，原成绩不改写。按用户确认的先测试后发布流程，本轮先绑定冻结候选安装包完成真实接入和工程验收；通过后才准备公开发行，发行后另核对匿名下载。不得将受控提供者测试说成Qwen实测，也不得自动扩展旧额度。

另发现旧评测脚本把五个场景的运行接口同时附给每个任务，导致全栈任务被混入调度器开发要求；第二轮正式验收还因复用旧Unix账号被阻断。旧记录保留，但不能据此比较产品能力。新批次将需求、账号和安装完全隔离，遵守调用方输出上限；一笔中断请求继续保留unknown并按119667tokens完整预留上界计账，获得用户明确批准后在剩余额度/原截止时间内重测。
