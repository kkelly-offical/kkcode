# 1.0.12 设计基准导出

[Figma 审核入口](https://www.figma.com/design/B7xZDsDx6Bj1LiNZ2wThpk?node-id=69-1128)。用户已确认按本设计实现 Android、Web、Windows；macOS / iOS 应用暂缓。

- `exports/`：22 张已确认页面与状态图，包含 Windows 主屏、项目路径选择、历史与搜索，以及 Android 主要页面。
- `assets/`：26 个从 Figma 原节点导出的 SVG。应用已有的像素伙伴和图标来自同一原始资源，落地时优先复用对应组件。
- `export-manifest.json`：每个导出文件的大小及 SHA-256。截图只作为视觉参照，不用作应用界面背景。

## 本轮不可丢失的要求

保留任务卡、运行横幅、活动面板及三栏布局。优化颜色、按钮、图标、边框和间距，避免重复状态区与视觉堆叠。普通对话不凭空显示任务或验收状态。

项目按设备身份与完整工作目录区分；切换项目不迁移已有会话、不停止正在运行的任务。历史定位后能返回阅读位置，向上阅读不被新输出打断，进入会话定位最新消息。

设计中的模型、任务、耗时、上下文和文件修改均为示例。运行时必须使用真实接口数据；无数据时不填入示例数值。Windows 客户端使用已有权限和网关协议。

实现与验证进度见 [1.0.12 清单](../../implementation-1.0.12.md)。
