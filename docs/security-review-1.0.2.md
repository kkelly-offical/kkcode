# 1.0.2 安全复核

此文是代码与验收边界说明，不是企业生产安全认证。签名私钥、模型凭据、SSO
数据库与生产域名配置未写进仓库。没有关闭 CodeQL 查询或批量消除告警。

## 本轮新增边界

- 图片完整解码、字节/像素/数量/缓存限额。SVG 在严格 XML 树检查后渲染静态
  像素，禁用文档实体、脚本、外部引用、外部 CSS、嵌入图片和 foreignObject。
  历史兼容只修改请求副本；不会因为坏历史而让新消息反复发送同一无效图片。
- MIME 判断以真实字节为准，冷缓存/热缓存结果相同；大 base64 输入不再使用
  可能耗尽正则栈的重复四字符分组。坏 padding/非规范编码仍拒绝。
- 客户端图片只按已授权 session/message/index 读取，不接受文件路径，不自动
  请求第三方图片地址。共享会话的图片读取与该会话的访问权一致。
- Auto 审查使用当前会话连接，独立、无工具、有超时和输出限制；坏 JSON、异常
  或取消不意味着同意。单次允许不缓存为长期能力。硬拒绝和必须人工的规则
  保留；Hook 改写后重新计算实际命令/路径，不审查一个旧参数再执行新参数。
- 异步命名 CAS 保证人工命名优先，按实际模型计费且不伪增轮数。标题/审查的
  provider 必须是显式 own property，拒绝原型名称；临时 options 用新对象构造，
  不沿动态索引删除继承属性或修改原配置。
- 回退在跨进程锁内同时更新消息和 parts，陈旧快照不能覆盖新消息；先写私有
  备份，再更新历史，客户端按 historyRevision/session.rewound 重置旧缓存。
- Worktree 新目录逐级授权、realpath/私密路径/物理身份检查，不能覆盖现有目录；
  选定已知 ref 的提交对象，不拼 shell 命令。切换/checkout 禁用钩子、fsmonitor
  以及已初始化子模块的过滤器，不自动 stash/reset/clean/push。
- Browser 每会话临时 profile，默认 Chromium sandbox，所有网页 HTTP(S) 由
  地址固定的 Node 请求通道处理，私网源需显式打开、云元数据恒拒绝；兜底浏览器
  代理拒绝直接出网。WebSocket/Service Worker/下载/弹窗禁用。不把浏览器自动化
  宣称为完整宿主隔离，也不接管个人 cookie/profile。

## 静态告警如何处理

首轮 `16bcb9a` 的 CodeQL 新报 4 条标题/审查 provider 动态属性删除（#58–61）。
已改成显式 own-property 检查、拒绝原型键和局部不可共享 options，加入继承键
不能触发推理的测试；不是把它们直接标成误报。回退备份路径（#57）改为复用
已验证 shard 的 basename，避免安全前置条件隐藏在另一个函数里。

此前版本仍有经逐类复核的开放告警，见 [1.0.1 复核](security-review-1.0.1.md)：
受授权根检查的文件路径、固定私有存储目录、所有者配置的模型/企业网关、目录
缓存密钥摘要、文件提及 token 转义等。保留真正的规则和数据流检查，不能把
“工作流执行成功”写成“零告警”。最终数量、扫描 commit 和结果记入
[实施台账](implementation-1.0.2.md)，以最终扫描而非这段说明为准。

本地发布门禁包括源/暂存区/实际 npm 产物秘密扫描；`npm audit --omit=dev`
当前报告 0 个漏洞。临时实验仅针对自有 localhost/WireGuard 和专用 AVD：浏览器
显式实验地址直连、模拟器用可恢复的蜂窝测试路径，均不改变宿主代理或生产 TLS。
正式 Android 保持既有签名，非调试包必须由系统确认安装。
