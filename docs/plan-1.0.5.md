# 1.0.5 Preview 全面升级与 1.1.0 成熟版门禁

状态：用户已批准实施；本文件是开发契约，不是已交付功能清单。
实际完成与测试证据见 [实施账本](implementation-1.0.5.md)。发布稳定基线仍为 1.0.4。

## 固定产品决策

- 大任务默认交付经过深度验收、可合并的 GitHub PR / GitLab MR；不隐含自动合并、部署或发版。
- 先确认目标、禁区、验收和预算，然后在独立工作区自主推进。主工作区和用户原有改动受到保护。
- 委托任务严格隔离，普通交互保留兼容行为并展示保护状态。
- 默认所有职责沿用会话模型；用户可显式配置职责模型，不静默换供应商。
- 项目可约束模型和外部工具的数据出口；组织 deny 不被项目规则覆盖。
- 项目经验可自动积累，必须有来源和删除/纠正功能；跨项目个人偏好需确认。
- Browser 包含隔离浏览器和本机已登录 Chrome/Edge 授权桥接，三系统验收。
- 不开发跨设备浏览器调度、整机桌面、Web/Android 浏览器直播或专用监管面板。
- 网页操作、Office/PDF/Markdown 产物进入统一证据与验收体系。
- 全部核心链路在 1.0.5-preview.N 内完成。1.1.0 只承担冻结、复验和成熟发行。

## 共同架构

单内核；CLI/Web/Android/ACP 经 SDK/协议访问任务协调、模型、上下文、策略和工具。
任务账本、原始证据、模型上下文投影和长期记忆分离。摘要不是授权或完成事实。

领域对象：TaskContract、RunRecord、ActionIntent、ArtifactRef、ContextRevision、
CandidateRevision、VerificationReceipt、ScopedGrant、ProviderProfile。
所有对象版本化并具备运行时校验；模型提出变更，宿主核准授权、状态和验收。

新运行账本使用独立 Node 存储进程和 SQLite/WAL；兼容 Node >=22.12。
大内容以私密不可变文件保存，先持久化内容，再发布引用。损坏不视为不存在。
旧 JSON 会话迁移必须可重复、先备份、可检查，不能补造已经被旧压缩丢弃的原文。

新增 SDK 能力组：runs、artifacts、memory、browser、forge、diagnostics。
维持现有 exports 和 headless JSONL；远程方法通过能力协商增量开放。
旧客户端/旧设备不支持时明确报告，不伪装成功。

## 工作包与交付标准

### W01 已知契约修复

- Anthropic 原生压缩参数、作用域、持久化和下一轮续接；原生能力不绕过预算保护。
- webfetch 声明/参数/手册与实现一致，正文读取有来源和边界。
- HTTP 逐跳校验、DNS 连接固定、跨来源凭据剥离、流式字节上限、取消和资源释放。
- 必需检查未执行不得算通过；用户确认的阻断性验收条件不能由模型单独删除。
- 以多轮 HTTP fixture、错误/取消/重定向/并发测试验证，禁止付费调用代替基础契约测试。

### W02 持久任务与副作用

- 运行/暂停/等待输入/等待审批/验收失败/未知结果/取消/完成具有明确状态。
- 先写操作意图，后执行，最后写回执；稳定逻辑 ID 与网络尝试 ID 分离。
- 进程接管使用拥有者和递增代次；旧执行者结果不可提升。
- 分类重试：读取、本地可核对写入、支持幂等的外部写入、不可查询的外部副作用。
- 未知副作用先核查，禁止盲目重放；停止保留候选，不删除工作。
- SIGKILL、锁竞争、满盘、损坏及过期执行者恢复必须有用例。

### W03 证据与产物

- 工具日志、网页、截图、Office、测试和补丁共享 opaque artifact 引用。
- 完整原文与模型短投影分离，支持不可变游标分页、搜索、下载和来源定位。
- 对账号/项目/会话/任务校验权限；远程不暴露宿主路径。
- 默认单产物128 MiB、单任务1 GiB、单设备10 GiB，可由高级配置调整。
- 已解决且无引用临时产物30天；活跃、未决和待验收内容不可自动驱逐。
- 原件缺失/过期/超配额必须明示；旧历史不自动清理。

### W04 上下文与记忆

- 先归档大输出与按需工具，再有损摘要；保护用户约束、未完成任务和tool配对。
- prepare/generate/validate/CAS/commit：不长时间持锁等待模型，提交前检查观察版本。
- 新消息/撤回/切模型/双压缩必须保真；摘要空、失败、缩水不足保留旧有效状态。
- 最终完整请求含 system/schema/hook/media/output reserve；不fit则可解释暂停。
- 原生状态限定端点、模型、凭据和revision；不可跨供应商复用。
- 项目记忆来源可见、可纠正/禁用/忘记，个人偏好确认后跨项目复用。

### W05 模型与提示词

- 端点/协议/模型能力档案区分配置、目录、实测、推断与unknown。
- Chat、Responses、Anthropic、本地vLLM协议回放；工具、thinking、媒体、usage和停止语义。
- /models 不冒充完整能力发现；部分输出后不盲重放。
- 职责模型、标题、记忆和压缩全部受项目出域约束。
- 分层prompt、稳定缓存前缀、工具文档一致性、同模型A/B。

### W06 隔离、授权与出域

- 控制面持有凭据；任务进程最小环境、独立scratch、无凭据目录和Docker socket。
- Docker OCI为首个认证严格委托后端；原生兼容后端不能未经测试宣称等价隔离。
- 隔离缺失fail-closed；网络默认不直连，通过宿主受控工具/依赖准备流程。
- 高影响授权绑定主体/任务/工具/目标/参数摘要/资源版本/有效期。
- Auto模型审查是辅助，不越过host策略；插件/Hook/stdio MCP独立可信边界。
- 测试秘密canary、目录别名、撤销/重放/跨账号、合法构建可用性。

### W07 仓库变更与独立验收

- 固定基线、脏树纳入策略、独立worktree；不自动stash，不改用户原目录。
- 先单写者+只读评审，再多写者独立worktree和持久所有权。
- 候选tree/patch/contract指纹与验收命令、环境、证据绑定。
- 实现代理不可自行降低用户验收标准；缺测试/未知/环境故障不变pass。
- 提升前重新校验基线、写意图、确认可用恢复点、应用、核对、收据、最后清理。
- 测试同目录用户并发编辑、候选变更失效、快照失败、提交边界崩溃。

### W08 GitHub/GitLab

- Forge adapter：仓库识别、任务分支、推送、草稿PR/MR、CI、评论、修订、交付状态。
- 授权来自任务契约；不自动合并，不修改仓库保护规则。
- 本地验收后更新草稿，远端检查绑定最新SHA，目标分支变更要重新验证。
- 人类review意见不是自动扩权；无权限/无远端/待人工审批保持明确阻塞。
- 两个平台使用专用验收仓库跑完整往返。

### W09 编排、组合与LSP

- 委派输入/证据/范围/预算/期限明确；结果按产物和验收核准。
- 持久租约/代次、有界并发、依赖、取消、通知和逐动作审批聚合。
- 增强已有只读并行/batch；实验代码组合无环境权限，叶子工具逐次治理。
- 按需TS/JS、Python、Go、Kotlin诊断与符号能力，故障不拖死会话。
- 同条件实测没有收益的复杂编排不进入默认路径。

### W10 Browser/WebBridge

- 隔离Playwright：多tab、页面版本元素引用、iframe/弹窗、受控上传下载、截图与诊断。
- bridge固定版本官方Playwright MCP扩展，由KK包装；按任务授权tab group，不暴露全部raw工具。
- Chrome/Edge三系统，凭据留本机；登录/验证码人工处理，禁止绕过网站安全控制。
- Web/App仅必要截图、引用、成果与待处理提示；没有实时监管面板。
- 录制生成工具为opt-in实验：限定站点/时间，脱敏，生成候选，审核/隔离测试/锁版后启用。
- 接口变更使recipe失效；不长期全量抓包，不自动安装生成代码。

### W11 Office/PDF/Markdown

- 隔离、按需的锁版文档工具包；使用python-docx/openpyxl/python-pptx/LibreOffice及PDF/OCR工具。
- DOCX常用结构样式；XLSX公式实际重算；PPTX真实渲染；PDF提取、表单、标注和生成。
- 扫描件OCR标记不确定；宏、外链、嵌入、加密/签名材料先识别限制，不自动运行。
- 原件默认保留，新版本产物可下载；不支持的复杂对象不悄悄丢弃。
- 字体/版式/公式/来源必须实际验收，不以文件存在代替完成。

### W12 生态协议与SDK

- MCP工具/资源/prompt/分页/取消/进度/结构化及协商后的多轮输入；注解不是授权证明。
- 远程OAuth回调绑定流程；PKCE/令牌留设备；SSO token不透传第三方。
- Skills限制/渐进加载/隔离语义落实；不支持字段明示。
- 插件固定来源/version/hash，升级能力差异与再授权。
- ACP能力与生命周期一致；SDK类型/schema和外部Node/browser消费样例。

### W13 多端/网关/可观测性

- 统一任务真相、候选和验收；紧凑任务卡、完成过程折叠、最终结果由收据支撑。
- context估算/实测/累计明确；记忆可管理；中文错误含副作用状态和恢复建议。
- 保持CLI终端输入/光标/鼠标/主题，Web/Android不新增权限档位或快捷键提示。
- 多端断线、重复事件、gap、换设备取消、Android SSH后台恢复回归。
- 网关继续账号/组织/共享/lease校验，正文默认不持久化。

## 统一验收与发行

- 契约、安全、恢复、集成、真实UI、真实模型和跨平台分层测试。
- 首批60个任务：仓库20、上下文恢复15、安全副作用15、日常文档10；40开发/20封存。
- 同模型比较Harness，跨模型比较产品；固定配置重复运行并报告波动。
- 真实模型目标独立验收成功率>=90%，不代表任意场景保证；关键安全/恢复用例全过。
- 禁止虚假完成、严重越权、密钥泄漏、覆盖用户工作与重复不可逆副作用。
- 付费测试预算默认0，执行前显式配置额度；不使用历史聊天中的凭据。
- Linux Node22/24、Windows22、macOS22、最低22.12；Web、Android JVM/UI/真实SSH，Chrome/Edge。
- 保留JS/Actions和真实Kotlin CodeQL；历史告警逐项复核，不关规则消警。
- 升级先备份，未来schema旧程序拒写；生产部署独立于npm发布。
- README、能力矩阵、操作/恢复/迁移手册与实际结果一致，实验标签不是未完成的借口。
- npm preview/GitHub prerelease/APK/镜像记录同提交hash；稳定latest保持1.0.4。
- APK versionCode每次公开发行递增，原证书不变；不发布私有测试包或密钥。
- 全工作包关闭、两轮完整候选验收、七天真实试用、阻断清零后，才进入1.1.0冻结/复验/发布确认。
