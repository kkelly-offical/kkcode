# KK Code 1.0.5 正式版

[文档导航](README.md) · [版本与升级](versions.md) · 2026-09-28

本次正式版本为 **1.0.5**，Android为 **1.0.5 / 10010**，沿用既有正式签名证书。
用户已授权从通过门禁的main发行；源码中的旧标记1.1.6从未公开发布，此次统一纠正为1.0.5。
实际产物和发行回执以[GitHub Release](https://github.com/kkelly-offical/kkcode/releases/tag/v1.0.5)为准，
不能仅凭源码版本、tag存在或流水线启动宣称发布完成。

## 相比已公开版本的变化

- 延续1.0.5-preview.0的持久任务、上下文／产物、记忆、职责模型、隔离、任务图、
  分域SDK，以及Browser/WebBridge、Office/LSP、MCP/ACP和插件治理；具体范围见[能力与边界](capabilities.md)。
- 配置出错时保留有效渠道并硬拦截危险执行；修复落盘竞态、空响应错误处理、模型目录连接释放。
- 加固附件引用解析、路径解码与Windows私密路径／ADS边界；保留逐条安全告警复核证据，
  不用关闭规则掩盖问题。源码专用记录见[安全复核](https://github.com/kkelly-offical/kkcode/blob/main/docs/security-review-1.1.6.md)。
- Web和Android增加3×3点阵思考动效，可展开流式内容，支持减少动态效果设置，原按钮布局不变。
- 停止后保留已收到的正文、思考和已执行工具结果；清理完成前显示“正在停止”，失败可重试。
  “继续”仅填入提示，仍需手动发送；不回滚文件、不自动重放已执行操作。
- 回合ID隔离迟到停止请求，控制权租约ID隔离旧清理，防止影响新回合、草稿或紧接着的命令。
- README与当前指南统一到1.0.5；未发行1.1.6期间的[维护记录](implementation-1.1.6.md)保留用于追溯。

## 发行与升级

npm稳定渠道为latest；Git标签为v1.0.5，GitHub Release不是预发布。
Android附件为kkcode-android-1.0.5.apk，并配套android-update.json；公开10008／10009用户
可按原签名身份升级。已有预览tag和npm preview指针不覆盖。

CLI、Android和网关分别升级。**公共网关镜像发布继续暂缓**，可从相同tag源码构建；
本次不会自动升级企业网关、测试VM或其他生产环境，也不开放新端口。

## 验收与仍未覆盖的内容

发行候选必须通过四平台工程检查、Web／Android、正式APK签名与安装、源码／产物密钥扫描、
不可变npm包和匿名下载校验。具体提交、流水线、证书及哈希写入本次Release回执，
此前维护分支或Preview的结果不冒充本次候选验收。

真实模型旧v3仍是108通过／11失败／1错误，v4专项仍是4通过／2错误，C04真实重连未覆盖。
本次没有新模型调用，不能把旧结果拼成全质量门禁通过。完整模型评测、GitLab真实MR、
长期实际使用与部分平台隔离仍在[Issues](https://github.com/kkelly-offical/kkcode/issues)中。
普通聊天不自动获得严格Docker隔离；Browser/Office/LSP需要各自的宿主依赖及授权。

这是1.0.5正式发行，**不是1.1.0成熟度里程碑已经达成**；后续仍按[原计划](plan-1.0.5.md)推进。
