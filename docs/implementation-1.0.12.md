## 实施与发行约束

- 原发行 tag、npm / APK 和独立显示补丁保持不变。研发分支 `codex/release-1.0.12-ux`。
- 不向设计示例填充虚构进度、剩余时间、模型参数或“已验证”状态；能力缺失有明确兼容行为。
- Windows 渲染界面与本机能力隔离；远端内容不得获得任意 Node / 文件系统调用能力。外部登录复用已有流程。
- 发布授权不等于替换未知生产网关。`coding.internal.zzheng.cn` 的部署位置仍未确定，不更新本机实验网关作为替代。
- 检查证据与失败修复记录写在本文件；完成状态以实际可复核结果为准。
