## 本轮实现

| 问题 | 最终行为 |
| --- | --- |
| 成功检查被普通只读命令或输出尾部误判失效 | 分开权限风险与已知修改；识别受限只读组合及不掩盖退出状态的检查 && 输出链，保留参数、目录、环境和顺序身份 |
| 验证失败反馈过晚、无法找到对应修复 | 下一步模型行动前给出去重、脱敏、限长的宿主定位；区分单项与有序组合复验，不接受打印PASS作证明 |
| 手工后台服务留下无主进程 | POSIX明确未收尾的 & 在派发前拒绝；保留受管后台、显式wait及有限测试程序的管理路径，CMD顺序语义不变 |
| 未执行检查产生虚假失败记录 | 宿主证明未派发时不制造检查证据；工具自报started=false不能冒充宿主证明 |
| 原子编辑、恢复和移除的别名/覆盖漏洞 | 写前检查普通单链接目标；私有随机暂存、元数据保留、预期字节核查及不完整恢复unknown；不承诺文件系统级CAS或ACL/xattr完整保真 |
| 未知副作用后仍派发工具或继续推理 | 在后续同批操作和模型请求之前暂停，保留规范配对与未派发回执，原拥有者核查后仍需新的真实验证 |
| 压缩保留旧附件正文与媒体 | 摘要区和最近保留区均归档为简短引用；文本搜索/分页、媒体单独召回；大量附件目录有界，重复压缩不重复保存提示 |
| Web配置冒烟启动竞态 | 等待真实已连接主页后再打开设置；生产UI布局和超时不变 |
