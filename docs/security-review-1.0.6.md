## 已确认并修复

1. **数据出域策略误锁全部工具**。Copilot 指出后复现：仅 `data_policy` 无效时，
   旧实现也设置权限加载失败标志，并丢弃同层其他字段。现对出域策略设 deny-all，
   同时独立校验本地权限，保留有效模型和 Agent 配置；真正无效的权限／不可解析文件
   仍暂停执行。readonly、manual、accept-edits 回归及真实 HTTP 零出站负控通过。
2. **纯空白被当成续写证据**。流式和非流式仅返回空白正文／思考且报告 max_tokens
   时，修复前受控测试各产生9次请求；修复后均仅1次并返回 failed，不伪造完成，
   不重放工具副作用。有真实内容的有界截断续写保持原契约。
3. **目录请求拒绝后仍占用连接**。真实 HTTP 服务返回302但不结束响应体，旧实现
   拒绝跨源跳转后仍保留连接，等待请求超时。现在跳转响应及非成功响应主动取消正文；
   原失败用例通过，陷阱地址仍零访问。没有为释放连接而跟随危险跳转。
4. **NOTICE 版本元数据滞留1.0.2**。PR #23 改为引用 package.json，补版本文档回归；
   不改许可证、归属或致谢，也不把准备中的1.0.5说成已公开发行。

同时从远端可编辑配置视图移除内部 `permission._load_error`；真实执行标志仍保留
在内核中，客户端使用只读 `_diagnostics`，不能通过保存诊断来解除限制。

## 17 条开放告警的逐组结论

| 告警 | 核查与处理 | 仍需注意 |
| --- | --- | --- |
| #30–35、#39–41（路径） | RPC/SSE 输入到会话／重放文件。保留 ASCII 1–128 字符白名单、核心原型键拒绝、重放 nofollow／nlink／inode 检查和私密原子写入；现在直接从白名单匹配结果构造 basename，便于数据流审查。穿越、类型强转、控制字符、硬／软链接与128字符边界回归通过。 | 本轮没有复现远程路径穿越；不等于同一 OS 账号任意篡改私密父目录也受隔离。文件名构造加固不是权限替代品。 |
| #37、#56（路径） | 文件浏览在 realpath 前检查词法授权范围，再检查规范路径、私密目录及文件身份；拒绝未授权 UNC，合法大小写／目录别名保留。真实越界、符号链接、硬链接和私密路径负控通过。 | 全目录授权仍只覆盖普通目录，不暴露凭据／系统私密路径；不提供针对同账号任意复制内容的 DLP。 |
| #43（SSRF） | 模型目录入口保留工作区信任、出域策略、凭据传输检查；分页与跳转固定同源，跨源陷阱零访问。另修复上面的未关闭响应体。 | 用户明确配置的本机／企业内网是支持的用途，不能仅因 URL 动态就禁掉；仍须信任所选模型服务。 |
| #54、#55（SSRF） | 网关由用户选择，公开发现不带登录凭据；后续 HTTP 禁止重定向、WebSocket 禁止跟随跳转，令牌响应不能覆盖网关。登录、刷新、307/308和WS跳转已有真实双端点负控，继续复跑。 | 企业网关本来就在信任边界内；本次未增加任意远端代连或扩大网关权限。 |
| #20、#21（散列） | 用途是模型目录缓存命名空间，不是密码验证。现使用带目录专用域标识的 HMAC，绑定实际凭据、协议、端点和渠道，不再把环境变量名称误当凭据身份。密钥轮换隔离、重启缓存回放、原值不落缓存及变量改名回归通过。 | 不是密码存储安全升级或防离线猜测承诺。旧缓存键失效后需重新发现一次；用户模型配置不修改。 |
| #19（转义） | `formatMentionPath` 是自定义文件引用语法，不是 shell 转义或 HTML 清洗器。现有反斜杠、引号、空格及 shell 元字符往返测试通过；额外双写反斜杠反而改变文件名。 | 不可把该函数输出当作安全 shell 参数；本轮不靠屏蔽规则消除此告警。 |

上述分类是代码／负控结论，**不是所有告警已经关闭**。main 的告警状态只有在修复
获审、合并且对应扫描完成后才能更新；PR 扫描的绿色状态也不表示历史告警全无。
