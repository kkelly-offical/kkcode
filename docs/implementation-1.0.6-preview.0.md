## 产品契约

Agent、Auto、YOLO 共用完整的编码、验证与委派能力，仅审批策略不同。Ultra 在公共内核上增加阶段编排与目标验收；Plan 允许只读探索、规划和会话内任务清单，不授予项目写入权限。三端保持一个模式选择器和原有按键位置。

授权范围、企业策略、私密路径保护、未知副作用与验收证据不因 YOLO 而失效。停止不回滚；恢复必须核对已有结果，不能重放未知操作。

后台复用既有worker，持久化校验先于模型调用；父会话取消会传到真实worker。
严格任务图继续要求宿主能力，不能退回普通控制器。

自由文本的非只读`write_scope`不是精确文件路径沙箱；只读范围有执行期拦截，续接

## 后台会话归属补充

后台兼容别名 `background_output`、`task_get`、`task_output`、`task_list`、
`task_parallel`、`task_stop`、`background_cancel` 也按当前会话的精确父级归属过滤；
旧记录没有归属证明时不能由模型读取或取消。取消在检查点锁内再次校验归属及运行
尝试，不会因为等待锁期间任务变化而取消其他工作。仅完全不在会话中的可信宿主
直接调用保留全局管理兼容能力；该能力不是模型参数，也不是远程客户端权限。

子代理列表先按父会话筛选，再分页，不再被其他近期会话挤出。单个父会话超过1000条
子记录会明确返回 `child_list_overflow`，阻止用不完整列表宣布全部完成；当前尚未提供
该极端规模下的完整分页展示。对应归属／列表／子代理／后台锁组合26/26通过，无跳过；
这是本机工作树专项，不替代最终候选的跨平台验收。
