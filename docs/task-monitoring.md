# 跨端任务查看、停止与证据

[文档导航](README.md) · 当前源码：1.0.6（正式版）；[发行状态](versions.md)

## 普通会话的紧凑待办

CLI、Web与Android读取同一份会话ToDo快照，折叠为一行“已完成/总数、进行中、受阻”，
需要时展开负责人、依赖和子代理状态。多项可同时进行；不把模型自称完成或提供引用
当作已验证，也不显示虚构百分比。取消项单独计数，空列表隐藏。

清单跨回合、关闭界面和重连保存在被控电脑上。初始加载、回放缺口和后台子任务终态
重新读取规范快照；旧revision、旧会话／设备响应不能覆盖当前清单。未收到更新时界面
展示的是最近一次已知状态，不是独立的实时执行证明。

这里的子代理状态只读，不增加远程启动、续接或中断按钮。`error`、`blocked`、
`incomplete`、`unknown`不能显示为成功；等待结束也不等于验收通过。此清单与下面
`runs.v1`严格任务的宿主验收状态是两套不同含义的记录。

## 严格委托任务面板

Web 与 Android 的设置 → 工作区 →「委托任务」展示当前设备、当前会话下的持久任务。
原来的设备／会话首页和聊天按钮位置不变；普通聊天不会为了显示卡片自动创建委托任务。
被控电脑和中继网关均需要支持 `runs.v1`。旧设备会明确提示升级，不把不支持误报为空列表。

## 状态不是完成承诺

| 状态 | 含义与下一步 |
| --- | --- |
| 等待输入 | 合同已建立但还没执行，或上一回合已收束；不是后台正在运行。 |
| 运行中／等待确认 | 模型、工具或宿主审批仍在进行。 |
| 已暂停／已取消 | 停止请求已持久化；若回合或操作仍在途，界面继续显示收尾提醒。已有文件和远端副作用不会撤销。 |
| 结果待核查 | 可能已有副作用，但缺少可靠结果；必须在被控电脑核查，不能直接重发工具。 |
| 验收未通过 | 验收失败、缺证据或结果不确定；模型说“完成”不能替代验收。 |
| 已完成 | 宿主确认当前候选的验收与交付，且没有未收束动作、任务图或费用预留。 |

任务列表按真实游标分页。记录按序号继续读取；手机面板最多保留最近读取的 200 条记录，
不是删除电脑上的事件历史。任务详情定期刷新，切换设备、账号或会话后丢弃旧请求结果。

## 暂停与取消

只有设备实际所有者可以操作；共享会话即使具有聊天控制权限，也不能停止所有者的委托任务。
用户点击后再次确认本次观察的任务版本和执行代次。若任务在确认期间变化，服务端拒绝旧确认，
需要刷新后重新确认。停止通过持久控制通道通知原宿主，不抢占活跃执行租约。

远程面板不开放新建任意任务、接管、解除未知结果、修改合同、恢复推理或最终核准接口。
这些操作仍在被控电脑的可信宿主入口完成，不能用模型 JSON 的 `approved: true` 代替。

## 预算显示

普通计费任务展示总额度、已结算费用、执行中预留、未知费用的保守预留上界和固定截止时间。
普通零额度表示未允许新的模型推理，不是免费或无限使用。未知预留不是供应商实际账单。

只有被控电脑的可信宿主显式批准并验证本机免费模型后，任务才显示「本地免费」，以及
`请求名额 已预留次数/总次数`、`累计预留 token 已授权上界/总上界`。这里的 token 是保守授权
上界，不是实际用量；已经结束的调用也不退还名额或累计预留，重启不能重置，期限仍然有效。
调用结果未知时明确提示「调用结果待核查」，不把零美元误报为已经核查或无限可重试。
远程投影只含四个额度计数，不包含本地监听进程、文件描述符、执行文件路径、地址、凭据或路线身份。
此能力不是远程传入 JSON 即可启用的开关，普通零预算行为不变。

模型请求与子任务先在 SQLite 事务中预留额度，再发送请求。并发子任务使用父任务共享总额度；
子任务自己的请求也有独立明细。崩溃或接管时未结预留成为未知，不因为重启获得新额度。
只有输入／输出用量都来自完整供应商回执时才能按实际用量结算；将缺失字段补零不算计费证据。
期限和总额由宿主冻结，恢复不自动延长或增加。账本自身不承诺外部供应商绝不会错误计费。

## 任务证据

远程只读取该任务公开的工具输出与交付文件。内部授权、原始系统输入、账号标识、主机私密路径
和内部验收资料不进入共享投影；用户也不能通过请求参数指定另一个账号或任意文件路径。

下载逐页读取并核对身份、偏移、结束标记及完整 SHA-256，再让用户选择保存位置。
文件不会自动打开或执行。关闭面板／切换连接会取消在途请求并清理客户端临时下载。
删除客户端副本不会删除被控电脑的审计证据，也不能撤销既有远端写入。

本机账本维护和恢复见 [持久存储 SDK](sdk-storage.md)，子任务图的核准、依赖与恢复见
[持久多代理任务图](task-graphs.md)。

## 停止与恢复

Web与Android用紧凑点阵显示思考或工具等待，折叠时不铺开日志，尊重系统减少动效设置。
停止后保留已生成文本、工具记录与输入草稿；界面区分停止请求、收尾和已停止，不把发出请求
当作进程已结束。停止不回滚文件或远端操作。继续由用户明确触发，并先检查已有结果和未知
副作用，不直接重放历史命令。

1.0.7支持在执行期间发送文字补充要求，CLI插话及Web/Android的「发送补充要求」都在安全执行节点送达。
原停止按钮仍可用；附件、模式切换和斜线命令留到下一轮处理。远端使用带当前executionId的turns.steer，
沿用原会话控制权和请求幂等机制。补充要求先持久保存；等待工具可提前返回，尚未派发的旧操作会让出执行。
取消或断线时未读要求保留为历史，在用户启动下一轮时置于新提问之前，不自动启动任务或覆盖更新的指令。

代理可用todowrite mode:merge局部修改计划，保留其他事项、顺序和原ID；blocked/cancelled可附reason，三端
保留可核查的任务状态。默认replace保留旧兼容行为；严格任务图、依赖、权限和预算不随计划改动放宽。
子代理汇报增加宿主整理的文件、检查、阻断和工作树交接信息；主代理仍须核对交付，完成状态不等于已验收。

## 1.0.11 子代理工作台

会话底部的“子代理”入口展示当前会话的协作卡片：任务说明、执行阶段、渠道与模型、思考档位、上下文及输出预留。页面可见且有运行任务时约每2秒同步状态，完成事件即时推送；这些是客户端状态读取，不是额外模型请求。重连读回当前状态，迟到事件不能将已结束任务改回运行中。

后台子代理完成后自动向当前主代理轮次投递结果。主代理可以继续独立工作；没有独立工作时由宿主等待，结果到达后继续。等待不消耗模型轮次，仍响应取消、插话及宿主截止；取消或关闭后不会由通知重新开启任务。`agent_wait`保留兼容调用，但不再向普通会话模型暴露。`task_output`用于额外日志或截断报告的按需读取，不要求循环查询。

设备所有者可在取得当前会话控制后停止单个子代理。停止保留已有结果及改动，当前主代理轮次不能自动重启用户刚停止的子代理。只读共享仅能观察，不能借子代理ID访问别的会话、修改模型参数或扩大权限。

原“委托任务”属于宿主持久任务合同，现从“持久任务与交付记录”独立进入，原有验收、预算和核查约束不变。普通子代理汇报不等于验证通过。

安卓右上角按钮打开紧凑操作卡片。KIKI的状态动作来自真实会话状态，可在伙伴面板关闭，并遵循系统动画设置；不会自动发送提示或执行操作。
