# KK Code 1.0.5 Preview 0

技术版本 `1.0.5-preview.0`，Android versionCode `10009`。
**已于2026-09-24公开预发布。** 实际发行、模型质量限制及产物哈希以
[实施账本](implementation-1.0.5.md)为准。npm `latest` 仍为1.0.4。

## 本轮重点

- 可恢复的严格任务：宿主确认合同、独立工作树、持久执行状态、拥有者代次与未知副作用。
  模型说“完成”不等于验收通过；暂停/取消也不代表撤销已经发生的修改。
- SQLite任务账本、迁移前备份及恢复检查；旧历史只能导入为暂停证据，不补造已丢失原文。
- 文本、浏览器及Office证据进入有范围和哈希校验的产物库；长输出按需检索/读取，
  不必为了恢复上下文再次运行有副作用的命令。
- 上下文压缩使用完整请求预算，严格任务显示“保守上界”（CLI为`BOUND`），
  与估算、计数API、最近响应usage区分。输入加最大输出都必须在批准窗口内。
  取消、并发消息变化、摘要没有真正缩小严格输入时保留历史；工具调用/结果保持配对。
- 项目及个人记忆有来源、更正、禁用和删除；跨项目个人偏好需要确认。
- 职责模型默认沿用会话模型，可明确路由；任务与子任务共用持久预算，未知用量不能当零。
- 严格Docker执行、项目出域政策与按次外部动作批准；工作区可写不等于允许网页提交。
- 严格Ultra绑定宿主验收定义；实现和独立验收使用不同副本，测试来源与候选指纹受保护。
- GitHub/GitLab交付接口、任务图、只读依赖成果、离线npm环境和语言服务的CLI/SDK入口。
- MCP/ACP表单、取消、进度及有界Schema验证；插件锁定与再授权检查。
- Web/Android增加会话范围的任务、证据和记忆管理，保留现有紧凑布局与单模式选择器。
- Web修复快速切换记忆范围时旧请求锁住新面板的竞态；迟到响应不能污染当前范围，
  新范围加载完成前不接受输入，原有控件布局保持不变。

操作入口见[严格任务](trusted-runs.md)、[上下文与Harness](context-and-harness.md)、
[模型职责](model-roles-and-profiles.md)、[持久预算](durable-budgets.md)、
[项目记忆](scoped-memory.md)、[任务图](task-graphs.md)、[SDK](sdk-guide.md)。

## 浏览器与文档

隔离Browser与本机Chrome/Edge授权桥接是两条不同路径，不提供桌面远控或跨设备浏览器调度。
Bridge需要用户批准页面范围，截图另行授权；不开放任意原始CDP/JS。
站点工具录制/生成须显式选择、审查，仍是实验能力。

严格Browser默认只读网络；写入型网页交互须合同范围与当前动作批准，未知结果不自动重试。
严格任务暂不支持development/WebSocket模式；普通交互式Browser的开发模式不因此移除。
浏览器必要截图/证据在对话里展示，没有新增Web/Android浏览器直播面板。

Office/PDF/Markdown使用独立离线解析环境，支持的格式、转换和限制见
[宿主服务](host-services.md)。复杂格式、宏或加密等不支持情形明确拒绝，保留原件。
不能把“生成了文件”当成内容和版式已经验收。

## 升级与发行渠道

安装本次自愿试用预发布：

```sh
npm install -g @kkelly-offical/kkcode@1.0.5-preview.0
kkcode --version
```

使用npm `preview`标签与GitHub预发布，不替换稳定版`latest`。
Android继续使用原项目证书，更新设置选择Preview；APK与`android-update.json`须配套，
安装仍经过Android系统确认。签名密钥不进入Git或CI，不发布任何私有更新测试包。
APK已公开上传并匿名重下核对，同证书v2/v3验签、非调试属性及更新策略通过；
专用模拟器安装/启动证据对应相同字节的候选包，没有冒充真实手机UI验收。

升级前备份设备私密状态与网关数据库；未来schema由旧程序拒写，恢复写到新目录，
不要手工删除未知动作或锁来绕过恢复检查。新任务/证据/记忆API需要相应设备端升级。
网关/Web与电脑CLI/App的部署分别进行，发布软件包不自动升级生产网关或示范虚拟机。
SSH仍仅Android直连，不增加Web SSH代理，也不把SSH私钥上传到网关。

新严格任务不会把普通聊天自动变成同等级隔离环境；目录许可、项目信任、工具审批、
浏览器授权与预算是不同边界，任何一个确认都不能代替其他确认。
