# 1.0.4 安全复核与验收边界

对应 [正式版实施账本](stable-1.0.4-worklog.md)。这是源码/协议/实验验收记录，
不是企业生产合规认证；公开发布、生产部署和第三方模型账号实测须分别记录。

## 本轮边界

- Responses 继续通过可信渠道解析、模型能力检查和 KK Code 工具执行器。调用参数
  未完整、重复 call_id、未收到完成标记、服务端过滤、未知托管工具均不执行半截工具。
  已有部分输出后不重放请求，避免重复可见输出或副作用。
- 每次 `store: false`，不用服务端持久对话。加密推理续接与 phase 仅存在设备私密
  历史；远端会话投影移除 opaque state。切换模型/地址/凭据或改写可见内容后不能
  复用旧状态。作用域使用带域标识的 HMAC，凭据作 MAC key，不序列化进历史。
- 没有用浏览器替模型抓取来源。仅用户点击时允许 HTTP(S) 浏览，拒绝凭据 URL、
  file/javascript/intent 等。Web 阻断嵌入远程图片/样式，来源标签不带 referrer、
  cookie/SSO 认证头；Android 使用可浏览的外部 Intent。原生/浏览器点击均有回归。
- API Key 错误脱敏在截断之前执行，避免截断留下半截 Key。App 编辑现有渠道不
  回填/保存脱敏占位，留空保留旧 Key；新表单显式空 Key 不借用环境中的其他凭据。
  更换地址/协议的临时目录请求不静默复用旧密钥。
- SSH 自动恢复不跳过主机指纹、系统权限或工作区信任；账号库仍只存元数据与已
  确认指纹，凭据仅在手机加密保存。RPC 代次检查阻止旧设备回包污染新设备；失败后
  不盲目重发可能有副作用的请求。连接断开不等于取消任务，原前台 Remote 生命周期不变。
- 空会话过滤和过程折叠仅改变呈现，不删除历史，不把失败折叠成已成功完成。
  Root/Host/Origin、HTTPS、附件保护、共享权限和头部身份规则均未放宽。
- Windows 发行门禁还暴露审计锁回收竞争，新增无随机延时的确定性反例可复现
  旧快照误删新锁。修复使用完整元数据原子发布、独占回收与二次身份核对。
  不能证明死亡的未知/外机持有者不会被清理；坏尾部/短读/读取错误拒绝续写。
  不自动修复、覆盖或删除既有审计历史；遗留不明锁/回收标记须本机管理员检查。
  Windows CI 增加 20 轮四进程争用验收，不跳过原有链完整性断言。
  修复 `d695c12` 的四平台 CI `35895409434` 与三语言 CodeQL `35895410356`
  已通过；Windows 3,200 条争用写入链验证通过，未新增开放静态告警。
