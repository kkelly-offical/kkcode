# 1.0.11 · 子代理协作与安卓交互

[版本状态](versions.md) · [实施与检查](implementation-1.0.11.md)

已发布 **1.0.11 稳定正式版 / Android10018**（npm latest），发行提交`a60d8b0`，沿用原签名证书。Preview及旧tag不变；[下载正式APK](https://github.com/kkelly-offical/kkcode/releases/download/v1.0.11/kkcode-android-1.0.11.apk)。

- 后台子代理完成后自动向主代理投递结果。主代理继续独立工作；没有独立工作时由宿主等待，结果到达再继续，不反复消耗模型请求调用`agent_wait`。
- Web／Android子代理卡片展示任务说明、当前活动、实际模型与渠道、思考设置、上下文及输出预留。前台自动同步，完成事件即时更新，旧事件不会回退状态；不暴露密钥或完整私密委派正文。
- 右下角“子代理”直接打开当前会话的协作面板；设备所有者可停止单个子代理，当前主代理轮次不能自动重新启动用户刚停止的子代理。原持久任务保留为独立高级入口。
- 安卓右上角使用紧凑操作卡片，重命名及删除确认按需打开。KIKI根据空闲、思考、执行、等待汇报、确认、结束、异常或断线呈现不同动作，支持减少动画。
- 纳入1.0.10后的默认模型思考入口、Kimi实际三档、通用直答标签及自动模型额度修复。

App、被控电脑的KK Code／remote、网关分别升级。旧网关可转发只读子代理快照；新增停止接口需要新版网关。未升级的电脑端不能获得新的自动汇报逻辑。此发行不自动升级其他生产网关，也不推送公共网关镜像。

权限、预算、范围及未知效果核查保留。子代理汇报不等于测试验收，取消不回滚已有改动；不自动恢复已经取消的任务。检查使用本地模拟接口、真实受控子进程和安卓模拟器，没有新增真实模型评测。
