# KK Code 1.0.4

正式版本：`1.0.4`，Android 版本码 `10008`。
发布状态与实际测试以 [实施账本](stable-1.0.4-worklog.md) 为准。
本说明覆盖代码与升级流程，不代表生产服务已经自动部署。

## Responses API 与运行时

- 新增独立 OpenAI Responses 协议，可从 CLI/Web/Android 渠道设置选择，沿用用户
  Base URL 动态发现模型；原有 OpenAI Chat Completions 和 Anthropic 不变。
- 支持文本/图片、流式思考摘要、Function 工具与结果回传、用量、来源链接、
  加密 reasoning 续接和 assistant phase；请求使用 `store: false`。
- 半截流和不完整工具不执行；首个输出前按策略重连，输出后不盲目重放。
  私有续接数据不发到 Web/App，也不跨模型/渠道/凭据重用；工具仍受原权限与审计约束。
- 修复上下文缓存把长工具结果截短再估算的问题；修复 SDK 省略 session/model/provider
  时不能按已声明的可选参数正常启动/续接的问题，保持 headless JSONL 契约不变。
- 音视频、OpenAI 托管工具、Background/WebSocket 不在本次 Responses 支持范围。
  配置、边界与故障排查见 [Responses API 指南](responses-api.md)。

## SSH 与设备管理修复

- 网关设备与 SSH 设备在顶部并列切换；点击当前已连接的设备只关闭菜单，
  不重复连接、不再弹凭据窗口。上方添加入口只添加网关，SSH 在下方独立区域维护。
- 自动恢复缺少本机凭据或主机指纹变化时只提示，由用户主动打开连接管理处理；
  首次连接/主动连接仍须确认指纹，不为消除弹窗跳过安全验证。
- 切换设备会清空旧机器的模型、渠道、目录相关状态；过期 RPC 返回不会覆盖新设备。
  模型设置保存在各台被控电脑，手机保存的 SSH 资料并不代表另一台电脑也配置了模型。
- SSH 仍仅 Android 直连。没有新增 Web SSH 或网关 SSH 代理，网关仍不保存私钥/密码。
- 关闭 App 不中断在途任务的生命周期不变：任务排空且 75 秒无客户端活动后退出。

## 空会话与中文错误

- 没有消息/运行内容的空草稿不显示在首页，正在执行的会话仍显示。
  这是显示过滤，不是删除；改名不会伪装成有消息。旧设备没有明确标记时保留显示，
  不根据“新对话”标题猜测并隐藏真实历史。
- 新版设备端在保存新会话前先校验模型和模式，错误选择不会遗留空记录。
- 修复本地/SSH 与网关 HTTP 错误处理器注册顺序，同时兼容旧版平铺错误响应。
  App/Web 不再只给出 Bad Request / Internal Server Error；常见问题提供中文原因与操作建议。
- 模型目录区分渠道不存在、API Key/权限、错误 Base URL、404、网络不可达等。
  模型 API 请求发生在被控电脑，`localhost` 是被控电脑自身，SSH 不会自动把
  手机或其他机器上的 vLLM 转发过去。明文 HTTP 凭据保护与工作区信任检查不变。

## 对话阅读体验

- Markdown 来源链接和明文网址可点击，由设备浏览器打开。Web 新开标签并使用
  `noopener noreferrer`；Android 使用系统浏览器入口。不自动抓取来源，禁止
  `javascript:`、`file:`、`intent:` 和夹带账号密码的 URL。
- Thinking 从开始阶段就可展开，收到文本后原位置实时更新；没有可展示文本时
  明确说明，不虚构模型内部思考。展开阅读时不会因每个新 token 强制跳回底部。
- 运行中保留过程细节；最终报告完成后，工具、思考和中间说明折叠为
  “已运行多少秒 / 多少次工具调用”。最终报告独立展示，点击摘要可以重开过程。
  缺少可靠时间时不伪造耗时，失败或尚无最终答案的过程不显示为成功完成。
- 这些变化仅影响呈现，不删除历史、工具输出、审批记录或审计事件。

## 升级

```sh
npm install -g @kkelly-offical/kkcode@1.0.4
kkcode --version
```

Android 在稳定更新渠道检查更新，并确认系统安装。APK 沿用原证书，不需要卸载。
完整修复需要同时升级被控电脑 CLI、网关/Web 和 App；旧端兼容不等于具备全部新功能。

建议顺序：先备份，升级实验网关和一台工作电脑，验证后再更新其余设备与 App。
工作电脑先等在途任务完成，沿用原来的 npm 用户/prefix 安装，再重新启动远控进程；
仅更新磁盘上的 CLI，不会把已经运行的旧 Node 进程自动换成新版。不要因此清除
账号绑定、SSH 凭据、已有工作区信任或企业数据库。

网关从本标签源码构建：

```sh
git checkout v1.0.4
docker build -f deploy/Dockerfile -t kkcode-gateway:1.0.4 .
```

先备份，再替换容器，保留数据库卷、环境配置、加密密钥与 OIDC 回调。
发布包不会自动部署你的生产网关或示范主机，也不自动推送公共容器镜像。
