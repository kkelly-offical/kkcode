# Windows 客户端

[文档导航](README.md) · [1.0.12 发行范围](release-1.0.12.md)

Windows x64 客户端提供本机工作区与企业网关两种入口。**1.0.12 正式版已发布**：[下载 Windows x64 安装器](https://github.com/kkelly-offical/kkcode/releases/download/v1.0.12/kkcode-windows-1.0.12-x64-setup.exe)，详见[版本页](versions.md)。

## 安装与开始

运行对应版本的 `kkcode-windows-<version>-x64-setup.exe`，选择安装目录。安装器面向当前用户，附带 Node 和搜索工具，无需先安装 CLI。项目需要的 Git、编译器及其他开发环境继续使用电脑上的现有安装。

打开应用后，通过左侧项目选择器或“工作区 → 打开项目文件夹”选取文件夹，在“模型”中设置当前电脑的模型渠道，然后开始对话。项目按完整路径划分；新对话沿用当前项目。切换项目只切换查看位置，不停止已经运行的任务。

“工作区 → 连接企业网关”接受 HTTPS 网关地址。登录继续使用网关原有授权流程，网关账户和远端电脑状态不复制为本机配置。切换回“返回本机”即可继续本机工作区。

## 阅读与任务

- `Ctrl+N` 新建对话，`Ctrl+K` 搜索对话，`Ctrl+O` 打开项目目录，`Ctrl+Shift+H` 返回本机。
- 对话记录按钮搜索当前已加载消息；需要更早内容时先加载历史。项目搜索也可查找当前项目中的对话标题。
- 手动阅读历史时新输出留在末尾；“回到最新”恢复跟随，“返回刚才的位置”恢复定位前的阅读位置。
- 活动面板集中显示待办、变更、子代理、持久任务与产物。工具记录不等于完整 Git 差异，待办完成也不等于测试验收。
- 外观、阅读宽度与字号保存在本客户端。模型、权限与远端任务设置作用于当前工作设备。

## 退出与更新

有本机任务运行时，关闭窗口会让你选择后台运行、停止并退出或返回。托盘可重新打开窗口；停止会等待服务收尾，已经发生的文件改动不会撤销。远程电脑上的任务独立运行。

“帮助 → 查看新版与发行说明”打开正式发行页，下载新安装器覆盖安装。1.0.12 是 Windows 应用的首个正式版本；本轮验证同版本重装和卸载保留数据，不能据此宣称已验证未来版本升级。暂不后台自动替换安装包。

本机配置与会话位于 Windows 用户应用数据目录的 `KK Code` 文件夹，Agent 状态在其中的 `agent` 子目录。卸载保留用户数据，重新安装可以继续使用。该位置与单独安装的 CLI 状态目录独立。

## 权限与连接边界

本机服务仅监听回环地址。网页渲染启用沙箱与上下文隔离，外部网关页面没有本机文件选择或 Node 调用权限。选取新项目经过原生目录对话框和既有私密路径保护。网关鉴权、接口及事件流继续经过该网关的 HTTPS 证书验证。

本版安装器未配置 Authenticode 签名，安装时可能显示未知发布者。SHA-256、签名状态与真实安装检查见[公开回执](https://github.com/kkelly-offical/kkcode/releases/download/v1.0.12/release-verification.json)。请从项目的正式发行页获取安装器并核对校验值。
