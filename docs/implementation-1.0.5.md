## 第二轮开发与集成（进行中）

以下是当前工作树的实际新增，不是发行回执，也不是 W01–W13 全部关闭。
仍在持续补验收和修复独立审查发现；最终全量数量以收口记录为准。

- `runs start/resume/pause/cancel/complete` 经明确合同确认、独立工作树和严格后端执行；
  工作区/账号绑定、稳定逻辑动作ID、版本/代次、回执和未知结果有真实存储约束。
  模型最终文本不直接完成任务。只读任务不扩大路径范围，未认证后端不回退宿主。
- 父任务/子任务预算在HTTP之前持久预留，缺失或不完整usage不能当零成本；
  真正SIGKILL后旧预留进入待核查且第二个宿主不再发请求。默认零额度，不调用付费模型。
  预算是治理上限和供应商回执估算，不能承诺第三方实际账单绝对等价。
- schema1→2 在锁内一致性备份、哈希核验后事务升级，旧writer有协议/代次栅栏。
  真实Docker 8MiB tmpfs满盘用例通过；未填宿主磁盘。备份恢复到新目录，不覆盖原件。
  `runs backup`、`runs migrate` 提供精确确认的实际操作入口，旧历史仅导入暂停证据。
- 工具文本、Browser、Office产物支持账号/项目/会话/任务隔离。共享访客按会话读取，
  对回包时撤销再次核验；私密批准记录不进入远程投影。Web/Android下载校验哈希，

### 网络、模型与上下文

- HTTP连接固定已验证的DNS地址，每次重定向重新校验；跨来源读取剥离非安全头，
  保留写请求的跨来源重定向拒绝。压缩前/后都有字节上限，支持取消和资源释放。
- `webfetch` 可提取静态HTML正文与链接；移除不存在的缓存/模型处理承诺，显式拒绝
  未实现的非空`prompt`，避免模型误以为已执行二次分析。
- Anthropic原生压缩显式启用，正确发送触发结构；完整响应后才能保存私密状态。
  状态绑定端点、模型、凭据及历史/回答，不进入Web/Android公开投影。
- 原生续接被拒绝时不能在旧预算下重发展开历史；累计计费与当前上下文分开处理。
  客户端摘要生成不长期持锁，提交时检查消息、模型与historyRevision。
- 非空摘要仍需让完整候选（含包装和产物索引）估算tokens严格减少，否则保留原历史。
  尾部保留边界向前扩展以保护工具调用/结果及交错依赖；无安全边界或孤立结果时
  明确停止压缩，不能删除结果来伪造合法历史。正向缩减不等于充分压缩或摘要无损，
  完整请求硬预算继续单独把关；已消费但未提交的摘要调用同样计入用量。
- 新出域配置详见 [data-policy](data-policy.md)：所有相关来源取交集，标题/压缩/
  审查与后台子代理继承限制。Browser撤销期间的DNS竞态也有回归。

### 持久存储与真实工具归档

- 独立Node SQLite进程，WAL/FULL事务，类型化IPC；CAS版本、拥有者代次、稳定动作ID、
  未知结果、候选/契约变更导致旧验收失效。进程环境不继承模型密钥和`NODE_OPTIONS`。
- 未决动作不能凭同ID重复调用；完成态必须有当前候选、非空必需验收及证据引用。
  **证据真实性、执行许可仍由可信宿主负责**，不能将写接口直接开放成模型工具。
- `sdk/storage`有独立类型声明；`kkcode runs list/show/events`仅巡检，不启动/重放任务。
  只读SQLite可能创建协调用WAL/SHM，不会创建任务或迁移业务数据。
- 原子私密产物存储，有界分页/字面量搜索/本地下载句柄、SHA-256、严格范围校验、
  配额和保留状态。普通大文本/Bash已在显示截断前归档，经正常工具权限按需读取。
- Bash原有1MiB捕获上限不变；超时/取消/达到捕获上限标记部分结果，不伪称完整。
  会话范围跨回合可读，但不冒充已接入RunRecord。身份改变不会自动迁移旧产物。
- 活跃内容不会自动清理。产物目录仍为有界原子JSON索引；崩溃孤件保留并计入配额。
  定时GC、目录修复、历史迁移、远程下载和多格式产物接线尚未完成。
